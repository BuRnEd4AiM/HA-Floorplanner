# Antwort auf #705: woher die Raumtemperatur kommt

Die Bilder in der Antwort auf [#705](https://github.com/BuRnEd4AiM/HA-Floorplanner/issues/705) (2026-11-10, Version 5.4.0). Der Wunsch: die Raumtemperatur soll die des Thermostats sein, ohne die anderen Sensoren aus dem Bereich zu nehmen (bei ihm macht ein dingz-Schalter, der von sich selbst warm wird, das Mittel falsch). Gezeigt im Wohnzimmer der Demo, das genau so einen Lichtschalter hat (23,1 °C).

- `1-temperatur-von.jpg`: das Feld „Temperatur von“ des Wohnzimmers mit allen Möglichkeiten und ihrem Wert (die Liste für das Foto aufgeklappt und das Seitenfenster breiter).
- `2-automatisch-thermostat.jpg`: die Kachel des Wohnzimmers im Live-Bild, links „Automatisch“ (22,3°, mit dem warmen Schalter), rechts „Thermostat“ (21,4°).

Gemacht mit `make_pictures.py <gebaute Beta-Demo> <ausgabe>`.
