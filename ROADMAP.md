# Roadmap

- [x] Walls, rooms, floors, snapping grid
- [x] 3D / 2D view, device placement and rotation
- [x] Entity binding, toggle, auto-save, undo

- [x] Settings menu (grid, units, defaults, theme, language DE/EN, shadows)
